# Changelog

## [0.1.0] - 19-09-2026

### Added

- Atomic shared ownership through `ownd::Strong<T>`
- Single-allocation construction through `ownd::MakeStrong<T>()`
- Copy and move ownership semantics
- Safe derived-to-base and const conversions
- Cross-type pointer comparisons
- Thread-safe reference counting across distinct handles
- Xmake installation amd external consumer validation
